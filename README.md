# Youtube Pandora! Android

Windows版と別プロジェクトのAndroid用アプリです。Android 10以降（64bit ARM / x86_64）向けに実装し、Android 16 / API 36をターゲットにしています。初版の試用APKです。実機の動作検証は未完了です。

## インストール

**[Android版APK v0.2.5をダウンロード](https://github.com/L1ZeroX/youtube-pandora-android/releases/download/v0.2.5/YoutubePandora-Android-v0.2.5.apk)**

[リリース一覧・更新情報](https://github.com/L1ZeroX/youtube-pandora-android/releases) / [Windows版](https://github.com/L1ZeroX/media-downloader)

v0.1.3では動画解析・変換に必要なライブラリーの参照先不足を修正しました。旧版で失敗した動画は、更新後に「再試行」または「ダウンロード」を押してください。失敗した場合は動画をタップし「エラーをコピー」で詳細を取得できます。

スマートフォンで上のAPKリンクを開き、ダウンロードしたファイルをタップしてください。Androidから求められた場合、そのAPKを開いたブラウザーまたはファイル管理アプリに「この提供元のアプリを許可」を設定します。更新時はアプリを削除せず、同じ署名のAPKを上書きインストールしてください。

1. URLを1行に1つ貼り付けて「情報を取得」。YouTubeなどの共有メニューから本アプリへ送ることもできます。
2. 保存する動画、MP4 / MP3、画質・音質・フレームレートを選びます。
3. 動画は内部ストレージの `Download/YoutubePandora!/mp4`、音楽は `Download/YoutubePandora!/mp3` に保存します。動画・音楽のMIMEを指定してMediaStoreへ登録し、保存完了後に公開します。動画の詳細画面からもファイルを開けます。

v0.1.2から上記の保存先を使います。Android標準のダウンロードフォルダー名は `Download` です。旧版で保存したファイルは元の場所に残ります。同じ署名鍵で作成しているので、アプリを削除せずAPKを上書きインストールできます。ギャラリーの表示名・反映タイミングは使用するアプリによって異なります（アルバム名は末尾の `mp4` になる場合があります）。

通知を許可すると、画面を離れている間も進捗と停止ボタンを利用できます。プレイリスト全体を追加する場合は環境設定で切り替えてください（1回につき最大500件）。既存のファイルは上書きしません。

## 機能

- yt-dlp対応サイトの公開動画、複数URL、プレイリスト、重複除外
- サムネイル、動画時間、進捗、停止、失敗分の再試行
- MP4（H.264 / AAC）、MP3（128 / 192 / 320kbps）
- 最高 / 1080p以下 / 720p以下、元のfps / 24 / 30 / 60fps
- ダークモード、背景画像、透明度、ぼかし、画像に合わせたボタン色
- 背景色の丸角ラベル（項目名は標準色・見出しは濃色）、サムネイル色の動画タイトル
- 設定・動画一覧の復元、アプリ内yt-dlp更新
- 処理ログ・エラー件数、ログのコピー・共有・消去

v0.1.5では変換のデコード・フィルターの並列数とエンコーダーの先読みを抑え、互換映像のfpsが指定値と一致する場合も再圧縮を避けます。処理途中のアプリ終了を次回起動時に検出し、Androidが残した終了理由（Android 11以降）、fps・解像度・メモリー状況をログに追加します。終了原因の特定と実機での改善確認は継続中です。

## アプリのバージョンチェック

v0.2.0以降は起動時にGitHub Releasesをバックグラウンドで確認し、新しいAndroid版がある場合だけポップアップを表示します。「環境設定 → 新しいバージョンを確認」から手動でも確認できます。ダウンロードなどの処理中や別ダイアログの表示中は通知を待機します。

現在の版・新しい版・更新内容を表示し、「APKをダウンロード」でブラウザーを開きます。ダウンロードしたAPKを開き、アプリを削除せず上書き更新してください。自動インストールは行いません。最初にこの機能のある版へ手動で更新する必要があります。

確認先は公開リポジトリ `L1ZeroX/youtube-pandora-android` の直近30件のReleasesです。`v数字.数字.数字` を数値で比較し、公開済みAPKがある正式版・試用版を対象にします。下書き・同じ版・古い版は通知しません。GitHubへのログインは不要です。通信失敗はログに記録し、通常の操作は続けられます。起動後に公開された更新は、手動確認または次回起動時に検出します。

v0.2.1では未処理のJava/Kotlin例外を、終了直前に専用ファイルへ同期保存します。次の起動で「クラッシュ詳細」として通常ログに取り込みます。OSの終了理由・中断記録には診断用の架空の例外スタックを付けず、実際の例外と区別します。v0.2.4では診断ログで特定した、進捗バーの値が不明へ切り替わった際のNullPointerExceptionを修正しました。

## エラーを調べる

1. v0.1.5以降に更新してから、問題が起きる操作をもう一度行います。
2. 画面下部の「ログを見る」または「ログ (件数)」を開きます。環境設定の「処理ログを見る」からも開けます。
3. 「エラーのみ」で失敗記録を絞り込めます。「コピー」は表示対象の記録をコピーし、「共有」はテキストファイルをAndroidの共有メニューへ渡します。

日時、アプリ・Androidバージョン、機種名、処理段階、ffprobe/FFmpegの終了コード、保存先、失敗の詳細を記録します。URLの詳細とAuthorization・Cookie等の認証情報は伏せます。ログは端末内のみで保持し、自動送信しません。

エラー件数が0でも、保存成功とは限りません。途中でアプリが終了したときは起動し直して、エラーのみの絞り込みを解除したログを共有してください。OSが終了理由を残さない場合もあります。

ログは再起動後も残り、端末内の保存量は約256KiB（終了直前の専用記録は別途最大約48KiB）、画面は最大300件・本文約48,000文字です。古い記録は順次入れ替わります。更新前の処理は遡って記録できません。消去操作はログだけに適用され、動画ファイルは消しません。

## 初版の範囲

Windows版とは別のネイティブUIです。背景は中央を基準とした自動トリミングで、手動トリミング、細かなレイアウト変更、GPUエンコード、Cookie指定、ライブ録画には対応していません。ぼかしはAndroid 12以降で表示されます。

互換性のあるH.264映像はfpsを変更しなければ再圧縮を避けます。それ以外はCPU変換のため時間がかかります。端末の空き容量はダウンロード素材・変換中ファイル・保存結果を含めて必要です。OSによる強制終了時は自動再開しません。サイト側の変更やアクセス制限で取得できない場合があります。

## 開発・ビルド（Windows）

Python 3.12以降で以下を実行します。JDK・Gradle・Android SDKはプロジェクトの `.tools` 内へ導入され、システムのPATHは変更しません。Android SDKのライセンスはセットアップ時に承諾します。

```powershell
python scripts/setup_build.py
python scripts/build.py
```

通常のAndroid Studioからも開けます。Gradle 8.13 / Android Gradle Plugin 8.11.1 / JDK 17以降が必要です。`local.properties` は各環境のSDKに合わせてください。

```powershell
python scripts/build.py assembleDebug testDebugUnitTest lintDebug
```

署名鍵や `.tools`、`local.properties` はリポジトリ・ソース配布には含めません。

配布用APKを作るには `python scripts/release.py` を実行します。初回に `.signing` 内へ署名鍵を生成します。このフォルダーは公開せずにバックアップしてください。同じ署名鍵を使わないと既存アプリを上書き更新できません。

端末または起動済みエミュレーターを接続した場合は `python scripts/build.py connectedDebugAndroidTest` で、合成動画の情報取得・MP4保存・24fps変換・MP3保存と画面操作を検証できます。テストが作った保存結果は終了時に削除します。

Android 16の16KBページ端末向けに互換モードを指定しています。FFmpeg内のWebP関連ライブラリー5本が4KBアラインメントのため、完全な16KBネイティブ対応ではありません。16KB端末での動作は未検証です。Google Play公開用ではなく、直接インストール用のAPKです。

## v0.2.4 の画面変更

動画カードはタイトルを上部に配置し、チェック欄の右に横幅いっぱいの16:9サムネイルを表示します。画像の上部にはサイト名と時間を丸角ラベルで重ねます。タイトル・ラベルはサムネイル色に同期し、画像が取得できない場合も表示枠を保ちます。

「リンクを追加」の横の「リンクを削除」はURL入力欄を空にします。「保存する動画」の横の「動画を削除」はチェックした項目を一覧から外します。保存済みのMP4・MP3ファイルは削除しません。処理中は削除できません。

## 通常版 v0.2.5 / ベータ版 v0.3.0-beta.1

環境設定の「ベータ版をダウンロード」から入手できます。ベータ版はアプリ名にBetaが付き、通常版と別にインストールされます。設定と一覧も別管理です。通常版の自動更新ではベータ版を案内しません。

ベータ版ではMP4のフレームレートに「60fps（フレーム補間）」を追加しています。元動画が30fpsなどの場合に動きを推定して中間フレームを生成します。元から60fps以上は補間を省略します。補間はCPUで処理するため時間がかかり、映像によって動きが崩れる場合があります。まず短い720p動画でお試しください。

署名付きビルドは `python scripts/release.py`（通常版）/ `python scripts/release.py --beta`（ベータ版）。Gradleのみの場合は `-PpandoraBeta=true` を渡すとベータ構成になります。


## v0.2.6 / v0.3.0-beta.2

「リンクを追加」を押すと、クリップボードにコピーしたテキストをURL欄の末尾へ改行して貼り付けます。「貼り付け」も同じ動作です。既存の入力は残し、空のクリップボードでは変更しません。「情報を取得」を押すと読み込みます。処理中は貼り付けできません。

環境設定の「リリース版に戻す」（通常版では「リリース版をダウンロード」）で、ベータ版よりバージョン番号が小さくても最新の通常版APKを取得できます。通常版とベータ版は別アプリのままです。ダウンロード後にAPKを開き、通常版の「Youtube Pandora!」を起動してください。既存の通常版設定・一覧は引き継がれますが、ベータ版の設定・一覧は移行しません。ベータ版を削除する必要はありません。


## v0.2.7 / v0.3.0-beta.3：背景の仕上がりプレビュー

「環境設定 → 背景をプレビュー・調整」で専用画面を開きます。背景画像と、パネル・文字・ボタンの表示サンプルを見ながら、背景の透明度・パネルの透過率・ぼかし・ダークモードを調整できます。

縦画面は上にプレビュー・下に調整項目、横画面は左右に並びます。調整項目をスクロールしてもプレビューは表示したままです。画像の中央切り抜き・透明度・ぼかしは実画面と同じ描画処理を使い、端末の画面比率で縮小表示します。

変更は即時反映・自動保存です。「完了」で環境設定へ戻ります。画像未設定・解除時は標準背景を表示します。
